# Baja AI Builders — bajaaibuilders.com

Landing page for **Baja AI Builders**, an independent, vendor-neutral community for developers, founders, students, designers, and creators building real things with AI across Baja California.

Live site: <https://bajaaibuilders.com> (GitHub Pages fallback: <https://baja-ai-builders.github.io>)

## Stack

Plain semantic HTML + CSS. No framework, no build step, no JavaScript.

```
index.html          The whole page
styles.css          All styles (brand tokens are CSS variables in :root)
assets/favicon.svg  Temporary >_ favicon
assets/og.png       Open Graph / social preview image (1200×630)
CNAME               Custom domain for GitHub Pages (bajaaibuilders.com)
.nojekyll           Disables Jekyll processing on Pages
```
